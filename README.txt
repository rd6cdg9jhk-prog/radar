LAUNCH RADAR iPHONE V1 — ORIGINAL BASELINE

This is the original iPhone prototype, not the later GitHub Pages V2.

Features:
- Live new-token feed
- Basic launch score
- $100 paper bankroll
- Manual PAPER BUY $10
- Manual SELL
- P/L and equity
- Trade log
- iPhone/PWA layout
- No wallet
- No real transactions

To use as a hosted web app, the files must be served from HTTPS.
Safari -> open the hosted address -> Share -> Add to Home Screen.

The feed uses wss://pumpdev.io/ws and provider availability/fields can change.
